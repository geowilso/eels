# updating instructions

- Opencommand prompt
- Navigate to project folder using
    - cd .. = go back one fodler
    - cd [folder] = progress to next folder
- git staus = check status
- git pull = get your local repo up to date
- make a new subfolder in the assets folder
- add files to this folder
- change audio file to .wav
- add new gallery item to code by copy and pasting then editing text and file paths
- save
- back to the command promt
- git add .
- git commit -m "comment"
- git push
- git status
- you are done
